# dwg

A simple one-page static site — one HTML file, no build step.

## Run locally

```sh
npm run dev
```

Then open http://localhost:3000. The page reloads automatically when you save a file.

No Node? Use Python instead:

```sh
python3 -m http.server 3000
```

## Project structure

```
index.html   # the whole site (markup + styles)
```
